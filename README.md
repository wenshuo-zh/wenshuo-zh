基于 Qt 5 和 C++ 的客户端/服务端通信练习项目。

- 使用 `QTcpSocket`、`QTcpServer` 和自定义 PDU 消息结构进行通信。
- 已编写注册、登录、用户查询及在线用户列表相关逻辑，使用 Qt SQL 访问 MySQL。
- 将客户端响应处理与服务端请求处理分别封装，整理连接与用户在线状态管理。
