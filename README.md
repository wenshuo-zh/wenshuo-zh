## 🚀 项目实践

### 基于 Qt 的 TCP 文件管理与即时通信系统

基于 Qt 5、C++ 和 TCP 实现的客户端/服务端应用，提供账号与好友管理、文本聊天和远程文件管理。

- 使用 `QTcpSocket`、`QTcpServer` 建立 TCP 通信，并设计自定义 PDU 消息结构。
- 使用 MySQL 和 Qt SQL 管理用户信息、在线状态及好友关系。
- 实现好友申请处理、文本消息转发与发送方回显。
- 实现远程目录管理、文件分块上传与下载，并支持空文件传输。
- 使用 `QThread` 与 queued signal 将上传文件读取任务交给工作线程，网络发送由客户端对象完成。

**项目状态：** v0.9 · 核心功能已完成并通过基础功能验证

**技术栈：** C++11、Qt 5、Qt Network、TCP、MySQL、QThread

[查看项目仓库](https://github.com/wenshuo-zh/qt-tcp)
